      About & Help

      VisioCirkit is forked from the original CircuiTikZ-Designer and operates with identical behavior. The original project was part of the Circuit2TikZ-Project started as a research project at the Institute of Electronics Engineering at the Friedrich-Alexander-Universität Erlangen-Nürnberg.

      If you find bugs or have suggestions, please feel free to contact us, preferably on GitHub.

      VisioCirkit GitHub
      📌 General Concept
      • Source of Truth: TikZ code is the single source of truth. Synchronizing code to the visual canvas will restructure your TikZ code and discard comments (% ...). Keep backups!
      • Multi-tab Canvas: Each tab manages its own canvas. Canvas state is saved locally, so reloading or closing the tab will not erase your drawing (though Undo/Redo history will be lost).
      🖱️ Mouse & Touch Actions
      Move Canvas Hold Right Click + Drag Touch: Two Fingers
      Zoom Canvas Scroll Wheel Touch: Pinch
      Reset View Double Click Canvas
      Selection Left Click + Drag. Use Shift to add, Ctrl/⌘ to remove.
      Draw Wires Drag with Left Click to preview, release to place point. Double-click point or press Enter to finish.
      Draw Straight Wire Hold Ctrl/⌘ while drawing wire.

      Tab management

      VisioCirkit (forked from CircuiTikZ-Designer with identical behavior) can manage a different canvas for each tab to allow multiple drawings at the same time.
