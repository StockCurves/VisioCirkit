# Component Drawer

The component drawer contains the built-in shape libraries and the CircuiTikZ symbol library.

## Shape Categories

Use **More Shapes** at the bottom of the drawer to choose which built-in shape categories are displayed.

- **Basic** includes simple drawing primitives such as text, rectangles, ellipses, polygons, lines, and arrows.
- **Flowchart** includes flowchart-specific nodes such as process, decision, document, database, and connector shapes.

Click **Apply** to refresh the drawer with the selected categories. Enable **Remember this setting** to keep the same category selection for future sessions in the same browser.

The shape category chooser only affects built-in shape categories. Custom categories and CircuiTikZ symbol groups continue to render independently.
